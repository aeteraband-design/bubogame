BUBOGAME — мобильная HTML5-игра про полёт совы и вопросы дня.

- index.html загружает текущую версию из version.json и открывает app.html.
- app.html подключает стили из css/ и скрипты из js/. Порядок подключения скриптов важен.
- Банк викторины лежит в quiz-new/. Проверка банка — node quiz-new/check.js.

Для локального запуска откройте терминал в папке проекта и выполните:

    python -m http.server 8080 --bind 127.0.0.1

Затем откройте http://127.0.0.1:8080/ в браузере.

При первом входе предложена регистрация по никнейму, почте и паролю. Подтверждение почты не требуется. Для проверки используйте отдельный пароль. Каждый созданный профиль начинает игру с нуля, а прежнее сохранение остаётся в браузере. Выйти или создать ещё один профиль можно на вкладке «Профиль». Для возврата используйте тот же браузер и никнейм или почту. Данные хранятся локально по адресу игры.

Кнопка «Начать полёт» открывает карту. После трёх бесплатных учебных труб сова проходит Ночной город, Дневной город, Венецианский карнавал, Замок алхимиков и Джунгли. В каждом районе своя коллекция, по умолчанию пять тем по 20 значков. Сбор двигает сложность от Суперлайта до Хард+. Затем нужно победить местного Смотрителя и забрать приз в рулетке. Карта показывает результат района по звёздам. Победа даёт одну звезду, победа с одной потерей даёт две, прохождение без потерь даёт три.

Первые два жетона местной темы открывают её в викторине на Суперлайте и Лайте. В полёте появляются только темы текущего района. На Венецианском карнавале монеты встречаются чаще при том же лимите находок. «Обо всём» доступно с начала. На бесплатных уровнях показаны открытые темы и те, что можно собрать в текущем районе. Админка меняет квоты отдельно для каждой темы района и позволяет запускать предпросмотр района или его босса. На вкладке «Вопросы» остаются настройки бонусов за полёт, тестовый доступ к сложностям и локальные замеры.

GitHub Pages публикует корень ветки main.
